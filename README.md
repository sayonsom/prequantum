## Quick Start

```bash
# Clone the repo
git clone https://github.com/sayonsom/prequantum.git
cd prequantum

# Install dependencies
pip install qiskit qiskit-aer numpy matplotlib scipy

# Run any example
cd chapter-02
python example_01_the_quick_win.py
```
